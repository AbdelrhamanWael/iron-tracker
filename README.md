# Iron Tracker Pro 🏋️‍♂️

A bespoke, high-performance web application for tracking workouts, progressive overload, and strict nutrition adherence. Built with pure HTML5, Tailwind CSS, and Chart.js, styled in a custom **Onyx & Raw Athletic Gold** aesthetic.

## ✨ Features

- **5-Day Workout Routine**:
  - Day 1: Push A (Dumbbell)
  - Day 2: Pull A
  - Day 3: Legs & Abs
  - Day 4: Push B (Barbell)
  - Day 5: Pull B
- **Interactive Exercise Imagery**: 39 custom illustrations for each exercise, stretch, and cardio session with a click-to-zoom Lightbox modal.
- **Tactile Rest Timer**: Floating timer dock with 60s, 90s, and 120s quick presets, play/pause controls, and audio chime alerts.
- **Set Completion Tracking**: Check off sets to calculate logged session volume in real-time.
- **Nutrition & Macro Tracker**: Dual-mode meal tracking (Baladi bread vs. Boiled potatoes), supplement checklist, and daily hydration tracker.
- **Analytics & Progression**: Weight trajectory tracking, weekly compliance rate, volume progression charts, and JSON data backup/export.
- **Mobile-First Touch Standards**: 44px minimum touch targets, fast responsive interaction, and 100% offline-ready with local storage.
